# Sprint 3 Review And Retrospective

## Review

Sprint 3 produced a working Python version of the Estalv-IA MVP. The main user flows from the previous prototype are still available, and the project now has tests and CI.

## Completed Increment

- Python web app for the MVP.
- Core finance logic separated from the interface.
- Local data persistence.
- Unit tests for the main logic.
- GitHub Actions workflow for build and tests.
- Updated documentation.

## What Went Well

- The team kept the original product idea while changing the implementation to Python.
- The finance logic is now easier to test.
- CI gives faster feedback after each push.
- The repository is more organized and easier to explain.

## What Could Be Improved

- The Kanban should be updated more frequently so that card status matches the repository.
- Notifications are still pending.
- Privacy/security is still basic because data is stored locally.
- Usability testing should be documented with real observations.
- AI-based recommendations are not implemented yet.

## Decisions For Sprint 4

- Move unfinished Sprint 3 cards into Sprint 4.
- Prioritize notifications and privacy/security.
- Add tests for any new notification logic.
- Prepare usability testing and final presentation material early in the sprint.
