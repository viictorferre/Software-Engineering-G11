# Sprint 4 Planning

## Sprint 4 Goal

Sprint 4 should move Estalv-IA from a working public preview toward a more complete delivery. The app already runs in Python, has tests and includes the first AI Advisor version, so the next work should focus on reliability, trust and final user value.

## Context From Previous Sprints

- Sprint 2 defined the first MVP flow for personal finance tracking.
- Sprint 3 rebuilt the prototype in Python, added local persistence, separated business logic and created automated tests.
- The public preview removed the internal Privacy tab from navigation and added a first AI Advisor page.
- The remaining work from the Kanban fits Sprint 4: notifications, stronger privacy/security, usability validation and final documentation.

## Sprint 4 Backlog

| Priority | Task | Reason |
|---|---|---|
| High | Implement notification system | Users should receive budget or spending alerts before limits are exceeded. |
| High | Ensure data security and privacy | Personal finance data needs clear privacy handling before the app is presented publicly. |
| High | Test notification system | Notification behaviour should be reliable and covered by tests. |
| Medium | Conduct usability testing | The team needs user feedback to validate whether the main flows are easy to understand. |
| Medium | Prepare project documentation and presentation | Final delivery needs a clear explanation of the product, technical decisions and sprint progress. |
| Medium | Improve AI-based saving recommendations | The current AI Advisor is a first approximation; the next step is improving the quality and presentation of the suggestions. |

## Sprint 4 Definition Of Done

- Notification behaviour is implemented and tested.
- Privacy/security decisions are documented clearly.
- Usability feedback is collected and summarized.
- The AI Advisor is reviewed and improved where possible.
- README and sprint documentation match the current state of the app.
- GitHub Actions pass before merging to `main`.

## Kanban Status

The Sprint 4 plan is based on the current Kanban objectives and the work that was not fully completed during Sprint 3.
